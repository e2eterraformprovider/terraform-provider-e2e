# e2e_container_registry (Resource)

Provides an E2E Container Registry resource.

This resource allows you to provision and manage Container Registry projects on your E2E infrastructure. When applied, it creates a new registry project. When destroyed, it is removed.

~> **Migration Notice**: This resource has parameter changes in v3.0.0. See the [v3.0.0 Upgrade Guide](../guides/upgrade-to-v3.md#affected-resources) for migration instructions.

<!-- schema generated by tfplugindocs -->

## Example Usage

```hcl
resource "e2e_container_registry" "registry" {
  project_id   = "12345"
  region       = "Delhi NCR"  # Use 'region' instead of deprecated 'location'
  project_name = "my-registry-project"
  prevent_vul  = true
  severity     = "high"
}
```

## Schema

### Required

- `project_id` (String) The project ID to associate the Container Registry with.
- `region` (String) Region where the Container Registry will be created. This is the standard parameter name for specifying the deployment location.
- `project_name` (String) The name of the Container Registry project.
- `location` (Optional, **Deprecated**) (String) **DEPRECATED**: Use 'region' instead. This parameter will be removed in version 3.0.0. The location/region for the Container Registry.

### Optional

- `prevent_vul` (Boolean) Whether to prevent vulnerable images (default: false).
- `severity` (String) The severity level for vulnerabilities (default: "low"). Allowed values: `"low"`, `"medium"`, `"high"`, `"critical"`.

### Read-Only

- `id` (String) ID of the Container Registry project.
- `status` (String) The operational status of the Container Registry.

### Computed (Deprecated)

- `setup_status` (String, **Deprecated**) **DEPRECATED**: Use 'status' instead. This parameter will be removed in version 3.0.0. The setup/provisioning status of the Container Registry. This is a computed attribute that mirrors `status`.
